# Changelog

## 0.1.1

- Negative prompt box in the Prompt group, saved between sessions. An empty box uses the default.
- The panel content scrolls, so the groups keep their full height on small windows.
- The release build is the one tested with IngeTrazo 0.5.9.

## 0.1.0

- First public release: capture the IngeTrazo viewport, redraw it with Stable Diffusion 1.5 (realarchvis SD 1.5 V2 with an LCM LoRA), with an optional 2x Real-ESRGAN upscale.
- Proportion (1:1, 4:3, 3:2, 16:9, 9:16, 3:4) and Viewport shape.
- Saves the result, the capture and nothing else.
- Tested with IngeTrazo 0.5.9.
